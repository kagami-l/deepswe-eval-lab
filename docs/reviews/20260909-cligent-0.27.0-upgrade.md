## 版本差异与问题处理

核对范围为上游 `v0.26.0..v0.27.0`，发布提交 `219b4f1`。

| 变更 | 对项目的影响 |
|---|---|
| 新增 `codex:usage` 诊断事件 | 原生终止事件前输出用量快照、保留基线、差值和报告/省略原因；补齐 CLI-010 缺失的定位证据 |
| 修复中断执行后的 Codex 基线失效处理 | 执行开始却未观察到原生 terminal usage 时，清除旧基线，避免把中断工作的用量归到后续恢复轮 |
| 新增独立的 `estimateCost` API | 可使用显式价格或 models.dev 价格估算已报告 token；为 CLI-009 提供替代能力，不会补齐 Codex 原生 cost |
| 开发依赖安全更新 | 涉及 Vitest、Hono、js-yaml、nanoid；发布包的运行依赖、peer 要求及 Node 18.3.0 最低运行版本不变 |

Codex 仍按线程累计快照做差；正常报告仍标记 partial，因为 exec 不汇总后代线程。
计数下降、可选字段变化、缺少基线或子集无效时仍会省略 tokens，新版会说明原因。
CLI-010 昨日成功修订轮的具体原因尚不能确认，不能宣称此次修复必然解决那个样本。

`estimateCost` 的估算与原始 `DoneUsage.cost` 分离，保留 token coverage、价格来源、
费率和假设。models.dev 缓存有效期为 24 小时，刷新失败可显式标记 stale；没有 token
时返回 unavailable。调用方仍需解决精确 provider/model 对应及可用价格，不能假定
任意模型都能自动估价。本次未新增价格表或接入估算，原统计脚本继续展示上游报告费用。

## 实施

- runtime package.json、package-lock.json、本地安装及 shared manifest 的 cligent
  均固定为 `0.27.0`；lockfile 使用 `https://registry.npmjs.org/` 正式 tarball。
- runtime version 更新为 `0.7.0`，使后续评测使用新的运行镜像标识。
- Codex SDK/CLI `0.151.0`、Claude SDK `0.3.251`、OpenCode SDK/CLI `1.18.25`、
  Gemini CLI `0.57.0`、Kimi Code `0.39.1` 均保持当前上游测试组合；0.27 没有改变这些目标。
- 原事件持久化无须修改即可接收 `codex:usage`。新增 runner 回归覆盖 reported/omitted
  两种诊断在 round/global 文件中的保留、先于 done 的顺序，以及不把累计快照当成本轮用量。
- 保留 unknown/partial 统计语义、watchdog、权限 fail-fast 和进程清理；此次更新没有
  提供删除这些措施的依据。
- dogfooding CLI-009/010 已追加进展，均保留 Open，避免将估算能力或诊断增强等同真实修复验收。
